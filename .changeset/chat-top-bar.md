Chat top bar now says which conversation is open: the session title (its name, else its first message; the folder name until it is listed) with the session's state dot, "folder · model", "read-only" when read-only and, on desktop, the connection state under it. On the phone, ☰ carries an amber dot whenever anything waits for you (an inbox question or a session waiting for you), with the counts in its tooltip and label. The remaining actions (search the web, model, reset assistant, star, close / reopen) sit to the right of the title. A read-only session shows a ■ Stop in its read-only bar while the agent runs, replacing the settings strip's Abort.
