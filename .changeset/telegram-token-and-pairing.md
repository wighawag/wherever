The assistant can now be reached on Telegram, and only by you. With `assistantFolder` set (and this server holding the folder lock), set `"assistantTelegram": {"enabled": true}` and give the bot token through `WHEREVER_TELEGRAM_TOKEN`, `WHEREVER_TELEGRAM_TOKEN_FILE` (a file holding the token, for secret managers) or `assistantTelegram.token`, never on the command line. Both variables are removed from the server's environment at startup so the agent's shell cannot read them. If the token file cannot be read, Telegram is disabled with a loud error and the server keeps running. wherever long-polls the Bot API and saves the polling offset in the state dir, so a restart neither replays nor loses messages. Pairing needs a one-time code shown in the new "Assistant on Telegram" settings section: send `/pair <code>` to the bot. Anyone else writing to the bot is ignored and gets no answer. `assistantTelegram.userId` pairs a fixed user instead. Once paired, `/start` and `/pair` are refused, and "Re-pair" in the settings drops the pairing and issues a new code. This release covers connecting and pairing: your messages already reach the assistant session (visible in the web), and replies on Telegram come next. With `assistantFolder` unset, or Telegram not enabled, nothing changes: the token file is not read, nothing polls and nothing is written.
