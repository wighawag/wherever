Rename a session from the sidebar: the row ⋯ menu now has Rename (after Star, main list only, never on the read-only page). It opens a small prompt prefilled with the current name; Enter or Save renames, Escape, Cancel, an empty value or an unchanged name cancel. The new name shows in the folder list and the Live strip through the normal relist, and a refusal (a terminal whose wherever extension is too old, a session with no message yet, a load in progress) shows its message in the prompt and leaves the name unchanged.
