Session list: the filter row now holds the filter box, ☰ and +. ☰ opens the view options (By folder / By owner, Show closed, Refresh, and a new "Only starred"), so they no longer take a permanent row, and + opens the same new-session form the "Create New Session" row used to. "Only starred" lists only starred sessions in the folder list and the By-owner view (an unstarred owner of a starred session stays there, dimmed), never filters the Live strip, and is remembered on this device. The read-only page's ☰ holds Only starred and Refresh.
