# Decisions: live-strip-in-session-list (2026-07, task `live-strip-in-session-list`)

1. **Strip placement: outside the scroll area, between the filter box and the folder list.** The task says "under the filter box" and the spec says "pinned at the top"; putting it above the scroll container keeps it visible while scrolling folders. The 6-row cap and the collapse keep it bounded on mobile. Alternative: first item inside the scroll area (scrolls away). Touches only `SessionBrowser.svelte` layout.
2. **Row status = the presence's own `status`, not the full `presenceLine`.** The row already shows the label (first role) and a state badge, so `presenceLine` would repeat both. Alternative: reuse `presenceLine`. Touches nothing else.
3. **Badge colours.** waiting for you = amber (as the presence line), running = brand blue (the presence line's non-human colour, and not amber like the working dot), waiting on a session = brand purple. Alternative: emerald for running, rejected because emerald is the folder row's "active" dot.
4. **`LiveStrip` gets a `presence` prop besides the suggested `rows`, `currentSession`, `onOpen`, `labelOf`**, to read the status line; the rows keep the exact `{session, folderName, state, label}` shape the sibling by-owner view will reuse. Alternative: add `status` to the row.
5. **"+N more" expands for the current page life only** (not persisted); only the collapsed state is remembered, under `wherever-live-strip-collapsed` (`'1'` when collapsed, absent otherwise).
6. **Row label helper moved to core** as `sessionListLabel` (name, else `truncateLabel(firstMessage)` at 40 chars, else "Empty session"), identical to the folder row expression; the folder rows' inline markup was left as is to keep the diff scoped. The sidebar filter is `sessionMatchesFilter` in the same module, now used by both the folder list and the strip; it treats a missing `firstMessage` as empty instead of throwing (same result for every valid listing).
7. **Ordering tie-break:** an unparsable `modified` sorts as oldest (time 0); equal keys keep listing order (stable sort).
