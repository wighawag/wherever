# state-dot-legend: decisions made while building (2026-11-25)

Task `state-dot-legend` (spec `sidebar-compact-layout`, stories 1 to 4). In-scope choices a reviewer may want to ratify or reverse:

1. **The dot's closed input is the caller's `closed` flag, not `session.closed`.** `sessionDotState(session, presence, closed)` takes it as a third argument, matching `SessionRow`'s existing `closed` prop (both views pass `!!session.closed` today). Alternative: read `session.closed` inside the helper. Chosen so the helper follows whatever the row shows as closed. Touches: the Live strip task (pass the same flag).
2. **New name `DotState` with `idle` meaning "loaded, idle".** It extends `LiveState` with `idle | not-loaded | closed`. `idle` already meant "not live" in `ShipmatesSessionState`/`sessionLiveState`; in `DotState` it is narrowed to "resident and not live" (green), and a non-resident non-live session is `not-loaded`. The task names the states this way; recorded because the same word now has a narrower meaning in the dot legend than in the presence vocabulary. Code site: module JSDoc of `web/src/lib/core/state-dot.ts`.
3. **Long-press label UI.** A small bubble to the right of the dot for ~1.8 s, triggered by a 450 ms touch/pen press or a `contextmenu` event (Android long-press, desktop right-click). The click ending a long-press is swallowed so the row does not open. A right-click on the dot on desktop therefore shows the label instead of the browser's link menu (the task asks for a `contextmenu` preventDefault on the dot only). Alternative: a shared popover/tooltip component; none exists yet. Code site: `web/src/lib/components/StateDot.svelte` header comment.
4. **`anyoneWaitsForYou` takes the whole `ShipmatesState` plus the listed sessions** and returns `{inbox, sessions, waiting}`, all zero when `available` is false (same source and gate as `shipmatesBadge`). Only listed sessions count, so a presence the listing hides never lights it, like the Live strip. Touches: the `chat-top-bar` task, which will render it.
5. **Count dots reuse `liveCountDots`**, exported from `state-dot.ts` with `LIVE_DOT_ORDER` (need order: waiting for you, waiting on a session, running) so the Live strip header task can use the same order. The By-owner collapsed summary keeps the full `ownerGroupSummaryText` as the button's tooltip and accessible name, and shows `ownerGroupSessionsText` + the dots visually. Each count dot's label is "<n> <state label>".
6. **"Not loaded" grey made slightly more visible** (`bg-brand-text-muted/40` instead of today's `bg-brand-surface-3`, which was almost invisible on the sidebar background in the browser check), closer to the mockup's grey.
