# sidebar-header-tabs-current-line: decisions (2026-11-25)

1. **The 🔎 tab always searches the main sessions, even from the read-only page.** The read-only search stays reachable only through the "🔎 Search these conversations" link on the read-only page (as the task asks). Why: one icon keeps one meaning wherever you tap it. Alternative: the tab searches the read-only conversations when tapped on the read-only page (context-sensitive). Code site: `tapTab` in `web/src/lib/core/sidebar-nav.ts`. Touches: nothing else; the rail task (`sidebar-desktop-rail`) reuses the same tabs.
2. **Switching directly between tabs is allowed** (inbox to read-only, read-only search to inbox, ...): a non-active tab always opens its own view; only the ACTIVE tab goes back. Opening the read-only tab always refetches the read-only list, as the old row did.
3. **Current-session dot (`openSessionDot`).** Uses the listing entry (like `currentStarred` / `currentClosed`) plus the shipmates presence, and also treats this client's own `appState.isStreaming` as running, so the dot does not lag the listing; an open session not yet listed is shown loaded-idle. Alternative: listing only (grey until the list refreshes).
4. **Disconnected with a session open**, the line reads "Disconnected · <folder>" in red/muted (the dot is the red connection dot, not the session's state dot, since the state is unknown without a connection). ▾ still expands versions and Leave session.
5. **The instance badge is no longer inside the logo button**: only the logo is the "main screen" control, the badge is a plain label beside it.
6. **Tab label UI** (`web/src/lib/components/SidebarTab.svelte`): copied the `StateDot` long-press pattern (450 ms touch press or `contextmenu` shows a bubble ~1.8 s, the ending click is swallowed so a long-press never navigates); hover uses `title`, which carries a longer description (for example the Assistant's timezone) while `aria-label` is the short label. The active tab has `aria-current="page"`, a darker background and a blue underline; the Assistant while viewing it gets a blue tint (it is an action, not a view, so it is never "active").
7. **Drawer width** is `w-[86vw]` on the phone and `md:w-72` on desktop.
